# QUANXI LIMITED Website

A modern, responsive company profile website built for **QUANXI LIMITED**, an agricultural company specializing in agricultural equipment and modern farming solutions.

## 🌐 Project Overview

This website was developed to present the company's services, portfolio, management team, and contact information in a clean and professional manner.

## ✨ Features

- Responsive Design
- Modern Bootstrap 5 Layout
- Professional Navigation Bar
- Hero Section
- About Us Section
- Services Page
- Portfolio Page
- Contact Page
- Management Team Section
- Office Location
- Contact Form (Frontend)
- Smooth Hover Animations
- Professional Footer
- Font Awesome Icons

## 🛠 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- JavaScript (Bootstrap Bundle)

The goal of this project is to provide QUANXI LIMITED with a professional online presence that showcases the company's agricultural products, services, and contact information.
