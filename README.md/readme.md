# QUANXI LIMITED Website

A modern, responsive company website for QUANXI LIMITED built with HTML, CSS, Bootstrap, and JavaScript.

## 🌟 Features

- Responsive Navigation Bar
- Modern Hero Section
- About Us Section
- Services Section
- Portfolio Page
- Contact Page
- Mobile-Friendly Design
- Bootstrap 5
- Font Awesome Icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome

## 🚀 Getting Started

1. Clone the repository.
2. Open the project in Visual Studio Code.
3. Open `index.html` using Live Server.
